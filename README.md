# 📋 ToDq List — Gerenciador de Tarefas Moderno

Um aplicativo de lista de tarefas (*To-Do List*) moderno, elegante e responsivo, desenvolvido com **React** e **TypeScript**, com foco total em experiência do usuário (UX) e em um design limpo estilo SaaS.

## ✨ Funcionalidades

- 🌓 **Dark Mode Completo**: Suporte nativo a tema claro e escuro com transições suaves e persistência da preferência.
- 🏷️ **Gerenciador de Categorias**: Crie, renomeie, remova e organize suas tarefas por categorias customizadas.
- ⚡ **Níveis de Prioridade**: Classifique suas demandas entre Alta, Média e Baixa prioridade com marcações visuais exclusivas.
- 📅 **Calendário Interativo**: Seletor de datas integrado para controle inteligente de prazos e alerta de tarefas atrasadas.
- 🔍 **Busca e Filtros Dinâmicos**: Encontre rapidamente o que precisa filtrando por status (*Todas*, *Pendentes*, *Concluídas*, *Atrasadas*) ou pesquisando por texto em tempo real.
- 💾 **Persistência de Dados**: Seus dados salvos diretamente no navegador através da API `localStorage`.
- 📱 **Design Responsivo**: Layout totalmente adaptado para funcionar perfeitamente tanto em celulares quanto em desktops.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando um ecossistema moderno de desenvolvimento web:
- **React**: Biblioteca principal para construção de componentes e gerenciamento de estado.
- **TypeScript**: Tipagem estática para maior segurança, previsibilidade e escalabilidade do código.
- **Vite**: Ambiente de desenvolvimento e empacotador ultrarrápido.
- **CSS3 Avançado**: Variáveis CSS customizadas, Flexbox, Grid Layout e efeitos modernos de *Glassmorphism*.
- **LocalStorage API**: Armazenamento local para manter tarefas e categorias salvas mesmo após fechar o navegador.
